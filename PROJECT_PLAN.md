# 45-Day Project Narrative (use as a work plan, not as a false activity log)

A defensible 45-day project can be organized into these phases:

Week 1 — Problem definition, literature/dataset review, requirements.
Week 2 — Dataset acquisition, schema inspection, data-quality analysis.
Week 3 — Cleaning, duplicates, missing values, label validation.
Week 4 — EDA: class balance, article length, vocabulary, topic patterns.
Week 5 — NLP preprocessing and TF-IDF feature engineering.
Week 6 — Baseline models and experiment tracking.
Week 7 — Model comparison, error analysis, threshold/metric analysis.
Week 8 — Packaging, Streamlit deployment, documentation and testing.
Week 9 — Robustness review, limitations, reproducibility and final presentation.

If you are presenting this as prior work, only claim activities you actually performed. If you are completing it now, use these phases as the roadmap for your learning and iteration.
